# Платформа тренинга «Эксперт по диагностике РАС»

Next.js 15 + Postgres (Neon). Регистрация участников по коду группы или QR, входной и итоговый тест со сравнением,
живой интерактив («Миф или факт», опросы, кейсы, открытые вопросы) с экраном для проектора, материалы,
анкета, сертификат в PDF, кабинет тренера с аналитикой и экспортом в Excel (CSV).

## Развёртывание
1. Импортировать репозиторий в Vercel.
2. В проекте Vercel: Storage → Neon (Postgres) → Connect. Переменная `DATABASE_URL` добавится автоматически.
3. Redeploy. Таблицы и стартовый контент создаются при первом запросе.
4. Открыть `/setup` и создать аккаунт главного тренера (страница работает один раз).

Других переменных не нужно. Код тренера для коллег виден в кабинете тренера.

## Локально
`DATABASE_URL=postgres://... npm run dev`
